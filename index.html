Instalação e uso

Para instalar como PWA, publique os arquivos em hospedagem HTTPS. Depois abra o endereço no Chrome do Android e use o menu “Instalar app” ou “Adicionar à tela inicial”. O modo offline funciona após o carregamento inicial, quando o Service Worker estiver ativo.

Para publicar gratuitamente, GitHub Pages é uma opção de hospedagem estática HTTPS. O aplicativo não precisa de servidor próprio.
